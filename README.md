## 🧮 CalculatriceAPK

Application Android de calculatrice simple, rapide et intuitive.

## 📱 Présentation

**CalculatriceAPK** est une application Android permettant d'effectuer facilement les opérations mathématiques courantes.

L'application est conçue pour être légère, simple à utiliser et adaptée aux appareils Android.

## ✨ Fonctionnalités

- ➕ Addition
- ➖ Soustraction
- ✖️ Multiplication
- ➗ Division
- 🔄 Effacement des données saisies
- 📱 Interface adaptée aux smartphones Android
- ⚡ Application légère et rapide

## 🛠️ Technologies utilisées

- HTML
- CSS
- JavaScript
- Android WebView
- Gradle
- GitHub Actions
